# md2html, כל מה שהוא עושה

md2html הופך קובץ Markdown לדף אינטרנט אחד שאינו צריך שום דבר נוסף: בלי שרת, בלי רשת, בלי גופנים או סקריפטים מאיפשהו. הדף מביא איתו את תוכן העניינים שלו, חיפוש, ערכות צבעים בהירה וכהה, גודל טקסט, מילון מונחים, הערות שוליים, איורים שמוגדלים, קוד צבוע, מתמטיקה מסודרת ותרשימים. הדף הזה נכתב ב־Markdown והופק על ידי md2html, כך שכל מה שהוא מתאר פועל עליו בזמן שאתם קוראים.

## איך לקרוא את זה

- **פרק 1** הוא היכן md2html רץ, ואיך מתקינים אותו.
- **פרק 2** הוא הכול בטבלה אחת.
- **פרקים 3 עד 9** מראים מה הקורא מקבל, ומה הכותב מקליד כדי לקבל את זה.
- **פרקים 10 עד 12** הם ההגדרות, שורת הפקודה, ובטיחות ואיכות.

## 1. היכן הוא רץ

| | היכן |
|:--|:--|
| הכלי md2html | macOS (Apple silicon ו־Intel), Linux ו־Windows, מתוכנית Rust אחת בלי תלויות מעבר לספרייה הסטנדרטית; נבדק בשלושתן בכל שינוי |
| הדפים שהוא יוצר | הגרסאות העדכניות של Chrome, Edge, Firefox ו־Safari, במחשבים, בטאבלטים ובטלפונים, עם חיבור לרשת או בלעדיו; קוראי מסך והמקלדת לכל אורך הדרך |
| נפתחים מתוך | שרת אינטרנט, תיקייה משותפת, קובץ מצורף לדוא״ל, או ישירות מהדיסק: הדף הוא קובץ אחד |
| מודפסים או נשמרים כ־PDF | מכל דפדפן, עם פריסת הדפסה משלהם; `--pdf` יוצר את ה־PDF עצמו, בעזרת ה־Chrome, ה־Chromium או ה־Edge שכבר נמצאים במחשב |
| קוראים אלקטרוניים | `--epub` יוצר EPUB 3, התבנית הסטנדרטית של ספרים אלקטרוניים |
| שפות הדף | שבע־עשרה, כולל מימין לשמאל (פרק 8) |

ההתקנה היא בעזרת המתקין של Rust עצמו, מקוד המקור:

```console
$ cargo install --git https://github.com/githubrobbi/md2html --locked
$ md2html notes.md
md2html: notes.md -> notes.html (68504 bytes, 9 glossary terms, 0 of them shared)
```

## 4. כתיבה

Markdown רגיל, וכל מבנה נקרא היטב גם כטקסט פשוט. מה שכותבים מופיע קודם, בבלוק קוד; מה שמקבלים בא אחריו.

### הדגשה וקישורים

```markdown
**מודגש**, *נטוי*, ***שניהם***, ~~מחוק~~ ו־`קוד`.
[קישור](https://commonmark.org "CommonMark"), קישור חשוף,
https://spec.commonmark.org/0.31.2/, וסימנים כמו [V] שנשארים כפי שנכתבו.
```

**מודגש**, *נטוי*, ***שניהם***, ~~מחוק~~ ו־`קוד`. [קישור](https://commonmark.org "CommonMark"), קישור חשוף, https://spec.commonmark.org/0.31.2/, וסימנים כמו [V] שנשארים כפי שנכתבו.

### רשימות בתוך רשימות

2. שני.

- [ ] משימה פתוחה

## 5. קוד, מתמטיקה ותרשימים

הקוד צבוע עבור Rust, Python, JavaScript ו־TypeScript, Go, C ו־C++, Java, Kotlin, Swift, C#, ה־shell, SQL, Ruby, Lua, PHP, CSS, HTML, JSON, YAML, TOML, קובצי Dockerfile ו־diff, ולכל בלוק יש כפתור העתקה.

```rust
/// The whole page from one Markdown text.
fn main() {
    let page = md2html::render("# Hello\n\nWorld.", &Settings::default());
    println!("{} bytes, nothing to fetch", page.len()); // one file
}
```

```python
@cache
def area(w: float, h: float) -> float:
    """The area of a room."""
    return w * h  # square feet
```

```diff
- every quotation a note
+ a quotation is a quotation; a bold first word makes it a note
```

המתמטיקה מסודרת על ידי הדפדפן עצמו, כ־MathML, בלי סקריפט ובלי גופן להורדה. בתוך השורה, משפט פיתגורס הוא $a^2 + b^2 = c^2$, וזהות אוילר היא $e^{i\pi} + 1 = 0$; סכום בדולרים כמו $5 או $10 נשאר כסף. כנוסחה נפרדת:

$$
\int_0^1 x^2 \, dx = \frac{1}{3} \qquad \sum_{k=1}^{n} k = \frac{n(n+1)}{2} \qquad \sqrt[3]{27} = 3
$$

$$
\begin{pmatrix} a & b \\ c & d \end{pmatrix}
\begin{pmatrix} x \\ y \end{pmatrix}
=
\begin{pmatrix} ax + by \\ cx + dy \end{pmatrix}
\qquad
|x| = \begin{cases} x & x \ge 0 \\ -x & x < 0 \end{cases}
$$

### תרשימים

תרשים זרימה או תרשים רצף של Mermaid משורטט על ידי md2html עצמו, כ־SVG בתוך הדף: בלי סקריפט, בלי שום הורדה, בצבעי הדף עצמו בשתי ערכות הצבעים, והמילים שבו נשארות מילים שהחיפוש מוצא. זה ה־Markdown:

````markdown
```mermaid
flowchart LR
  md[notes.md] --> parse[קריאת ה־Markdown]
  parse --> render{תרשים?}
  render -->|זרימה או רצף| svg[שרטוט כ־SVG]
  render -->|סוג אחר| js[mermaid.js, אם ניתן]
  svg --> page([דף HTML אחד])
  js --> page
```
````

וזה מה שנוצר ממנו:

```mermaid
flowchart LR
  md[notes.md] --> parse[קריאת ה־Markdown]
  parse --> render{תרשים?}
  render -->|זרימה או רצף| svg[שרטוט כ־SVG]
  render -->|סוג אחר| js[mermaid.js, אם ניתן]
  svg --> page([דף HTML אחד])
  js --> page
```

תרשים רצף, ממוספר, עם הערה:

```mermaid
sequenceDiagram
  autonumber
  actor R as הקורא
  participant P as הדף
  participant S as החיפוש
  R->>P: Cmd K
  P->>S: פתיחת החיפוש
  R->>S: הקלדת "callout"
  S-->>R: הקטעים, הטובים ביותר קודם
  R->>S: Enter
  S-->>P: קפיצה, והדגשת המילים
  Note over R,P: בלי רשת, בלי שרת
```

סוגים אחרים (תרשימי עוגה, תרשימי גאנט, תרשימי מחלקות) משורטטים על ידי mermaid.js כשהכותב מפנה את md2html לעותק שלו (`--mermaid-js FILE`); הסקריפט נכנס אז לדף הזה בלבד. בלעדיו הם נשארים כקוד, ו־`--check` אומר זאת.

## 6. מילון המונחים, הערות השוליים, החיפוש והאיורים

פרק בשם „מילון מונחים” מחזיק את מילות הדף כטבלה. הוא אינו מודפס במקום שבו הוא עומד: במקום זאת, האזכור הראשון של כל מונח בכל פרק הופך למילה מנוקדת שמסבירה את עצמה כשמצביעים עליה, ולחיצה עליה קופצת לערך שבתחתית הדף, שמוביל בחזרה לשורה שקראתם.

איור מוגדל מעל הדף בלי לעזוב אותו. כשהוא גדול מהחלון, הוא עוקב אחרי הסמן, כך שמצביעים על מה שרוצים לראות.

## 7. שיתוף ודפים חיים

לכל כותרת יש סמל שיתוף אחריה; כל שורה בטבלה, איור, תרשים ובלוק קוד מציגים סמל כזה כשהסמן מצביע עליהם. לחיצה מעתיקה קישור בדיוק למקום הזה, ואומרת זאת; בטלפון נפתח במקום זאת דף השיתוף של המערכת. מסמנים כמה מילים, והדף מציע קישור בדיוק אליהן, שפותח את הדף בקטע הזה, כשהוא מודגש.

![סימון מילים מציע קישור אליהן.](capabilities/share.jpg){width=80%}

דף יכול גם לשמור על עצמו עדכני. `md2html --serve` מציג את הדפים במחשב הזה בזמן שהם נכתבים, וכל דף פתוח נטען מחדש ברגע שה־Markdown שלו נשמר. לדף שפורסם עם `--live` יש זמן חיים משלו: כשהוא נגמר, הדף מבקש מהשרת שלו את הקילובייט הראשון של עצמו, שבו נמצאת טביעת האצבע שלו, ונטען מחדש רק אם היא השתנתה. בשני המקרים הקורא נשאר במקום שבו היה: באותה פסקה ובאותו גובה, או, אם היא איננה עוד, בפרק שלפניה; מעבר לשפה אחרת שומר על המקום באותו אופן.

## 8. שפות

מילות הדף עצמו (החיפוש, תיבות ההערה, מילון המונחים, התאריכים, כל כפתור) קיימות בשבע־עשרה שפות: אנגלית, גרמנית, עברית, אינדונזית, הולנדית, ג׳אווית, יידיש, גרמנית תחתית, צרפתית, איטלקית, ספרדית, יפנית שנכתבת בשלוש דרכים (בקאנג׳י ובקאנה, בקאנה בלבד, וברומאג׳י), סינית מנדרינית בסימנים מפושטים ובסימנים מסורתיים, וקנטונזית. `lang: de` בראש הקובץ הוא כל מה שצריך. עברית ויידיש מוצגות מימין לשמאל, ותוכן העניינים מימין.

תרגום הוא פשוט קובץ Markdown נוסף לצד המקור, שנקרא על שם שפתו: `capabilities.de.md` הוא `capabilities.md` בגרמנית. md2html מוצא את הגרסאות הקיימות, מקשר אותן זו לזו במתג שבסרגל (הגלובוס), מודיע לדפדפנים ולמנועי חיפוש באמצעות `hreflang`, ונותן לכל אחת את המילים של הממשק שלה. הדף הזה קיים בכל שבע־עשרה השפות; הגלובוס עובר ביניהן, והדף נפתח בפסקה שקראתם.

כל תרגום מציין את המקור שלו ורושם את טביעת האצבע של המקור, כך שהדף יכול לומר איזו גרסה היא המחייבת, ו־`--check` מבחין כשהמקור השתנה מאז שנעשה התרגום:

```yaml
translated_from: capabilities.md
source_sha256: 5b0c...e1
```

לשפה שאיש לא תרגם אליה את הדף, הדפדפן של הקורא עצמו יכול לתרגם אותו, אם יש לו היכולת הזו (המתרגם המובנה של Chrome): במכשיר עצמו, כך ששום דבר לא יוצא ממנו, עם תווית של תרגום מכונה, ועם דרך חזרה למקור.

## 9. שמירת הדף

כפתור ההורדה שבסרגל מציע את מה שיש לשמור. הדף עצמו נקרא גם ללא חיבור כשהתמונות שלו נמצאות בתוכו (`embed: true`). להדפסה יש פריסה משלה: הפקדים נעלמים, כל קישור מודפס עם הכתובת שלו, שום דבר לא נחתך בין עמודים, והעמודים נושאים את הכותרת ואת המספר שלהם.

![אותו דף בהדפסה.](capabilities/print.jpg){width=55%}

`--pdf` מדפיס את הדף בעזרת ה־Chrome שכבר נמצא במחשב: בפריסת ההדפסה של הדף עצמו, הכותרות כסימניות של ה־PDF, הכותרת בראש כל עמוד ומספרו בתחתיתו. `--epub` יוצר מאותו דף ספר לקוראים אלקטרוניים, עם תוכן העניינים, התמונות, התרשימים והמתמטיקה שלו, והערות שוליים שנפתחות במקום שבו הן מוזכרות; md2html כותב אותו בעצמו. הקורא מוצא את שניהם תחת כפתור ההורדה.

## 10. הגדרות

ראש הקובץ, בקובץ ה־Markdown של המקור האנגלי של הדף הזה, נראה כך:

```yaml
---
title: md2html, everything it does
brand: md2html
kicker: Capabilities
version: 0.7.6
date: 2026-11-22
footer: Written in Markdown and rendered by **md2html 0.7.6** itself ...
csp: true      # only this page's own code may run
embed: true    # the screenshots are inside the page
---
```

| הגדרה | מה היא עושה |
|:--|:--|
| `title`, `description`, `author` | הכותרת, ותגי ה־meta לתצוגה מקדימה של קישורים |
| `lang` | השפה: מילות הדף עצמו והתאריכים בכל אחת משבע־עשרה השפות (`ja-Hira` היא יפנית בקאנה, `zh-Hant` סינית בסימנים מסורתיים, `yue` קנטונזית) |
| `translated_from`, `source_sha256` | לתרגום: המקור שלו, וטביעת האצבע של המקור בזמן שתורגם |
| `brand`, `brand_link`, `kicker`, `eyebrow`, `footer` | הסרגל, השורה שמעל הכותרת, האותיות הקטנות |
| `date`, `version` | התאריך והגרסה שמוצגים מעל הכותרת |
| `embed` | תמונות בתוך הדף, כך שהוא קובץ אחד |
| `csp` | Content-Security-Policy |
| `pdf`, `epub` | PDF ו־EPUB של הדף, לצדו |
| `live` | זמן החיים של הדף (`true` הוא שתי דקות, או מספר שניות): אחריו הוא נטען מחדש אם השתנה, והקורא נשאר במקומו |
| `large`, `toc`, `math`, `index`, `html`, `css`, `head` | אותיות גדולות יותר, תוכן העניינים, מתמטיקה, מנועי חיפוש, HTML עשיר יותר, עיצוב נוסף ו־head |

> [!TIP]
> עם `lang: de` החיפוש אומר "Diese Seite durchsuchen", כל תיבת הערה אומרת "Hinweis" או "Achtung", והתאריך נכתב "22. November 2026".

## 11. שורת הפקודה

```console
$ md2html notes.md
md2html: notes.md -> notes.html (68504 bytes, 9 glossary terms, 0 of them shared)
$ md2html docs/ -o site/ --nav
$ md2html notes.md --check
notes.md:12: a link points at #setup, which is nowhere on the page
notes.md:30: `plan.svg` does not exist next to this page
md2html: 2 to look at
$ cat notes.md | md2html - > notes.html
$ md2html notes.md --pdf --epub
$ md2html notes.md --serve
```

`--check` לא כותב דבר ומפרט את מה שהכותב צריך לבדוק, שורה אחר שורה, ויוצא עם 1 כשיש משהו: קישור לעוגן שאינו בדף, קובץ שאינו קיים, הערת שוליים בלי ההערה שלה, HTML גולמי שמוצג כטקסט, תרגום ישן יותר מהמקור שלו. כך הוא נעשה השלב האחרון של בנייה, או של עבודת סוכן. `--watch` מפיק מחדש בכל שמירה, `--nav` מקשר את דפי התיקייה עם הקודם והבא, וקישור לקובץ Markdown אחר מוביל לדף שלו.

## 12. בטיחות, איכות ונגישות

> [!WARNING]
> אפשר להפיק דף מ־Markdown שמישהו אחר כתב. md2html לעולם אינו כותב סקריפט מתוך הטקסט: HTML גולמי מוצג כפי שנכתב, מלבד כמה תגים לא מזיקים, וקישורי `javascript:` או `data:` מושמטים, בכל צורת כתיבה. מסמך אינו יכול לגרום ל־md2html לקרוא קובץ מחוץ לתיקייה שלו, ושום קלט, עוין ככל שיהיה, אינו יכול לתקוע אותו או לגרום לו לקרוס.

> [!CAUTION]
> `--html` מעביר HTML עשיר יותר (תמונות, קישורים, וידאו, SVG, פריסה), אבל לעולם לא משהו שרץ: לא סקריפט, לא מטפל אירועים, לא מסגרת, לא טופס.

מה נבדק בכל שינוי, ב־macOS, ב־Linux וב־Windows:

- 79 בדיקות שמפיקות דפים שלמים וקוראות אותם בחזרה, ובהן מקרי האבטחה והמקרים הפתולוגיים;
- 652 הדוגמאות של מפרט CommonMark, שמספר העוברות מהן יכול לעלות אך לעולם לא לרדת;
- כללי ה־lint המחמירים ביותר של clippy, וגרסת Rust הישנה ביותר שהכלי מבטיח להיבנות בה;
- בדיקת נגישות עם axe-core מול WCAG 2.2 AA, בשתי ערכות הצבעים וברוחב של טלפון;
- מעבר לחיצות ב־Chrome שמשתמש בכל פקד כפי שקורא היה משתמש בו, בעכבר ובמקלדת, בגודל הטקסט הרגיל ובגודל גדול יותר;
- דפים חיים, מקצה לקצה: טעינה מחדש כשמשהו משתנה, מקום הקורא נשמר, מעבר שפה שנוחת באותה פסקה.

ל־md2html אין קוד של צד שלישי, ושרשרת האספקה שלו מקובעת לגרסאות ונבדקה: ערכת הכלים, פעולות ה־CI, כלי הבדיקה. כל דף מסתיים בשורה שקטה אחת: נוצר באמצעות md2html, הגרסה שלו, וקישור למקום שבו md2html נמצא.

הדרך שעובר כל דף:

```mermaid
flowchart TD
  md[Markdown] --> blocks[בלוקים ורכיבים בשורה, בדרך של CommonMark]
  blocks --> settings[ראש הקובץ ודגלים]
  settings --> page[הדף: תוכן עניינים, חיפוש, ערכות צבעים, מילון מונחים]
  page --> check{--check}
  check -->|אין מה לתקן| out([קובץ HTML אחד])
  check -->|שורות לבדיקה| md
```
