# md2html に できる こと ぜんぶ

md2html は Markdown の ファイルを、ほかに なにも いらない 1まいの HTML ページに かえます。サーバーも ネットワークも いりません。フォントや スクリプトを どこかから もって くる ことも ありません。この ほうこくも そういう ページです。Markdown で かいて、md2html で かえたので、ここに かいて ある できる ことは ぜんぶ この ページでも はたらいて います。ひだりの もくじ、さがす しくみ、2つの テーマ、もじの おおきさ、したの カード、てんせんの ついた ことば、ちゅう、おおきく できる がぞう、いろの ついた コード、きれいに ならんだ すうしきです。

## この ページの よみかた

- **1しょう**は ぜんたいを 1つの ひょうに まとめた ものです。2ふんで よめます。
- **2〜6しょう**では、よむ ひとに なにが みえるか、そして かく ひとが その ために なにを かけば よいかを みせます。
- **7しょうと 8しょう**は せっていと コマンドラインの はなしです。
- **9しょうと 10しょう**は あんぜんと ひんしつ、そして バージョン 0.4 が できるまでの はなしです。

## 5. ことばの いみと ちゅう

## 6. さがす ことと がぞう

さがす ときは、ことばの いみの ひょうも ふくめて、ページの すべての ことばが さがす あいてです。けっかには それぞれの ことばが どこに あるかが でて、えらんだ ものは とんだ さきで ひかります。

![「callout」を さがした ところ。けっか ごとに しょうと ばしょが でます。](report/search.jpg){width=80%}

![さがして とんだ さき。こうもくが ひかり、みつけた ことばが めだって います。](report/search-landed.jpg){width=80%}

がぞうは、ページを はなれずに ページの うえで おおきく なります。がめんより おおきい ときは ポインターに ついて うごくので、みたい ところを さすだけです。

### げんご

この ほうこくは 17の げんごで よめます。えいご、ドイツご、ヘブライご、インドネシアご、オランダご、ジャワご、イディッシュご、ていち ドイツご、フランスご、イタリアご、スペインご、3とおりに かく にほんご（かんじと かなで、かなだけで、ローマじで）、かんたいじと はんたいじの ちゅうごくご（ふつうわ）、そして カントンごです。バーの ちきゅうの しるしで きりかえられ、ページは よんで いた しょうで ひらきます。

ほんやくは、もとの ファイルの となりに おいた、げんごの なまえを つけた べつの Markdown ファイルです。`report.de.md` は `report.md` の ドイツごばんです。md2html は そこに ある ばんを みつけて おたがいに つなぎ（ブラウザと けんさく エンジンには `hreflang` で しらせます）、それぞれに その げんごの がめんの ことばを わたします。さがす ところ、コールアウト、ことばの いみ、ひづけです。ヘブライごと イディッシュごは みぎから ひだりへ ならび、もくじは みぎに きます。

それぞれの ほんやくには、もとの ぶんの なまえと、もとの ぶんの フィンガープリントが かいて あります。だから ページは、どれが ただしい もとの ばんかを しめせます。また、ほんやくの あとで もとの ぶんが かわると、`--check` が きづきます。

```yaml
translated_from: report.md
source_sha256: 5b0c...e1
```

まだ だれも ほんやく して いない げんごでも、よむ ひとの ブラウザに その ちからが あれば（Chrome に ついて いる ほんやくの しくみ）、ブラウザが ほんやく できます。ほんやくは その きかいの なかで するので、かぞくの ページの なかみが そとへ でる ことは ありません。きかいが した ほんやくだと わかる ように かかれ、もとの ぶんに もどる ほうほうも つきます。

## 8. コマンドライン

```console
$ md2html notes.md
md2html: notes.md -> notes.html (68504 bytes, 9 glossary terms, 0 of them shared)
$ md2html docs/ -o site/ --nav
$ md2html notes.md --check
notes.md:12: a link points at #setup, which is nowhere on the page
notes.md:30: `plan.svg` does not exist next to this page
md2html: 2 to look at
$ cat notes.md | md2html - > notes.html
$ md2html notes.md --pdf --epub
$ md2html notes.md --serve
```

`--check` は なにも かきださず、かいた ひとが みなおす ところを 1ぎょうずつ ならべます。なにか あれば、おわりの ばんごう 1 で おわります。ページに ない アンカーへの リンク、ない ファイル、なかみの ない ちゅう、もじと して でて しまう そのままの HTML などです。だから、ビルドや エージェントの しごとの さいごの ステップに むいて います。`--watch` は ほぞん する たびに つくりなおし、`--nav` は フォルダーの なかの ページを「まえへ」と「つぎへ」で つなぎます。ほかの Markdown ファイルへの リンクは、その ページへの リンクに なります。

`--pdf` は、コンピューターに もう ある Chrome で ページを いんさつ します。ページ じしんの いんさつ ようの レイアウトで、みだしは PDF の しおりに なり、どの ページにも うえに だいめい、したに ページの ばんごうが はいります。`--epub` は おなじ ページから でんし しょせき むけの ほんを つくります。もくじ、がぞう、ず、すうしきが はいり、ちゅうは でて くる ところで ひらきます。EPUB は md2html が じぶんで かきだします。よむ ひとは どちらも バーの ダウンロード ボタンの なかに みつけられます。

`--serve` は、かいて いる あいだ、この コンピューターで ページを みせます。Markdown を ほぞん した しゅんかんに、ひらいて いる ページが ぜんぶ よみこみなおされます。`--live` を つけて こうかい した ページには、ページ じしんの きげんが あります。きげんが きれると、ページは じぶんの サーバーに じぶん じしんの さいしょの 1キロバイトを たずね、それが かわって いた ときだけ よみこみなおします。どちらの ばあいも、よむ ひとは いた ところに とどまります。おなじ だんらくが おなじ たかさに くるか、その だんらくが なくなって いれば、その まえの しょうに もどります。

## 9. あんぜん、ひんしつ、アクセシビリティ

> [!WARNING]
> ページは、ほかの ひとが かいた Markdown から つくられる ことも あります。md2html が ぶんしょうから スクリプトを つくる ことは ありません。そのままの HTML は、いくつかの あんぜんな タグの ほかは かいた とおりに でます。`javascript:` や `data:` の リンクは、どんな つづりで かいても とりのぞかれます。ぶんしょうが md2html に、その フォルダーの そとに ある ファイルを よませる ことは できません。また、どんなに わるい つもりで つくった にゅうりょくでも、md2html を かためたり おとしたり する ことは できません。

> [!CAUTION]
> `--html` を つけると、もっと ゆたかな HTML（がぞう、リンク、どうが、SVG、レイアウト）が とおります。でも、うごく ものは けっして とおりません。スクリプトも、イベント ハンドラーも、フレームも、フォームも です。

かわる たびに、macOS と Ubuntu で たしかめて いる こと：

- ページを まるごと つくって よみかえす 53の テスト。あんぜんの ための テストも はいって います。
- CommonMark の きまりの 652の れい。とおる かずは ふえる ことは あっても、へる ことは ありません。
- clippy の いちばん きびしい チェックと、この どうぐが ビルド できると やくそく して いる いちばん ふるい Rust。
- axe-core で WCAG 2.2 AA に そって する アクセシビリティの チェック。どちらの テーマでも、スマホの はばでも します。
- Chrome で すべての ボタンを つかって みる クリック テスト。キーボードと マウスで さがす こと、テーマ、もじの おおきさ、もくじ、がぞう、ちゅう、ことばの いみ、コピー、いんさつです。

いんさつには べつの レイアウトが あります。ボタンなどは きえ、すべての リンクは アドレスが いんさつ され、ページの さかいめで きれる ものは なく、どの ページにも だいめいと ページの ばんごうが はいります。

どの ページも、ひかえめな 1ぎょうで おわります。md2html で つくった こと、その バージョン、そして md2html の ある ばしょへの リンクです。

## 10. 0.4 が できるまで

はじまりは しらべる ことでした。よい Markdown の へんかん どうぐが なにを して いるか、ウェブの きまりが ページに なにを もとめて いるか、そして この コンピューターで どうぐが どう つかわれて いるか。さいごの ものが いちばん やくに たつと わかりました。4sons.com の 4つの ページづくりが、md2html の できあがりを あとから かきかえて、ブランド、げんご、フッターなどを かえて いたのです。その かきかえは それぞれ せっていに なり、ページづくりは あたらしい バージョンに あわせて 1ページずつ つくりなおされました。

へんかんの きまりが どう かわったかを、diff で みせます。

```diff
- a handbook subset, anything else shown as written
+ all of CommonMark, and anything else shown as written
- every quotation a note
+ a quotation is a quotation; a bold first word makes it a note
- the page's words in English
+ the page's words in English or German
```

その あと 0.5 で ふえたのは ずです。ここの ページが みんな とおる みちは こうです。

```mermaid
flowchart TD
  md[Markdown] --> blocks[ブロックと インライン、CommonMark の やりかたで]
  blocks --> settings[フロントマターと フラグ]
  settings --> page[ページ：もくじ、さがす、テーマ、ことばの いみ]
  page --> check{--check}
  check -->|なおす ところ なし| out([1つの HTML ファイル])
  check -->|みなおす ぎょう| md
```

---

したの ひょうでは、この ほうこくで つかって いる ことばを せつめい します。どれも、うえでは てんせんの ついた ことばでした。
